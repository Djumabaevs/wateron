ЧАСТЬ 1: СОЗДАНИЕ ТОКЕНА В REMIX IDE

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ШАГ 1: Открыть Remix IDE
- Перейти на https://remix.ethereum.org/
- Это бесплатная онлайн-IDE для разработки смарт-контрактов Solidity

ШАГ 2: Создать файл контракта
- В Remix: File Explorer → contracts → создать файл Wateron.sol
- Вставить код:

────────────────────────────────────────
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC20/ERC20.sol";

contract Wateron is ERC20 {
    constructor() ERC20("Wateron", "WTRN") {
        // 1 миллиард токенов, 18 decimals
        _mint(msg.sender, 1_000_000_000 * 10 ** decimals());
    }
}
────────────────────────────────────────

ШАГ 3: Скомпилировать контракт
- Перейти во вкладку "Solidity Compiler" (левая панель, иконка с буквой S)
- Выбрать компилятор версии 0.8.20+
- Нажать "Compile Wateron.sol"
- Убедиться что нет ошибок (зелёная галочка)

ШАГ 4: Подключить MetaMask
- Убедиться что в MetaMask добавлена сеть BNB Smart Chain:
  - Network Name: BNB Smart Chain
  - RPC URL: https://bsc-dataseed.binance.org/
  - Chain ID: 56
  - Symbol: BNB
  - Explorer: https://bscscan.com/
- Иметь немного BNB на балансе для оплаты gas

ШАГ 5: Задеплоить контракт
- Перейти во вкладку "Deploy & Run Transactions"
- Environment: выбрать "Injected Provider - MetaMask"
- MetaMask попросит подтвердить подключение — подтвердить
- Contract: выбрать "Wateron"
- Нажать "Deploy"
- MetaMask попросит подтвердить транзакцию — подтвердить
- Дождаться подтверждения транзакции в сети

ШАГ 6: Получить адрес контракта
- После деплоя контракт появится в разделе "Deployed Contracts"
- Скопировать адрес контракта

- Все 1,000,000,000 WTRN зачислены на кошелёк деплоера
